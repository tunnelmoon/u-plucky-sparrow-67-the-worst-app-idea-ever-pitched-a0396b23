# The Worst App Idea Ever Pitched

Entry for the make.fun bounty [The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

`main.ts` writes one sentence to `/output/entry.txt`:

> FridgeLight is the app that texts you every time your fridge light turns off, so busy professionals never have to wonder what their leftovers are doing in the dark, and it just raised $4 million in seed funding.

Run it with Node 22 (stdlib only):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
